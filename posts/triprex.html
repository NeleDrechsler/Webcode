"Trip-Rex" travel app

Planning a travel - especially in a group - can be overwhelming and chaotic. With the fictious app "Triprex", one can plan a travel together with other people. You can create different types of trips, record all the necessary details for each trip, and notify everyone involved.
Additionally, the app provides neccessary travel informations for different countries, like entry requirements, recommended vaccinations and cultural facts.

more information

Versions

A version for light mode and one for dark mode had been designed for a higher accessibility.




Login & creating a travel userflow

Inside the app, you can create an account to manage travels together with other users.

While creating a new travel, the user can decide between different kinds of travels. Depending on the chosen type, the user can select among various different options.
